Your first Retouch page

Everything on this page is meant to be changed. Work down the list, watch the counter in the bar, then press Save. Your edits land in this very file.

3

Make it bold

Select the words byte for byte below. A small pill appears above them. Press B, or ⌘B.

When Retouch saves, everything you did not touch stays byte for byte the same.

4

Use the page’s own colors

Select a word, open Color in the pill, and pick one. Only colors this page already uses are offered, so nothing looks pasted in. Try Styles too: it lists this page’s classes in plain words.

This sentence is waiting for a splash of color on one word.

5

Replace the picture

Click the image. Choose Replace image… and pick any picture from your Mac. It is copied next to this file when you save, and only the image’s address changes in the page.

7

Save

The badge in the bar counts your changes. Press Save or ⌘S. The first time, Retouch asks for the folder this file lives in, so it can write to it. Choose the Retouch folder in Downloads.

Then reload the page. Every edit is still there, because it is in the file now.

That is the whole product.

You just edited an HTML file without writing a line of code, and the file is exactly as your AI left it except for what you changed. Open any page it made for you and do the same.
